# Project Overview

## Project Type

End-to-end Business Intelligence / Data Analytics project.

## Business Domain

Retail Performance.

## Primary Tool

Microsoft Power BI.

## Objective

The objective of the project was to transform raw retail transaction data into an interactive analytical solution for evaluating:

- Sales
- Profitability
- Customers
- Salespeople
- Returns
- Targets

## Analytical Workflow

The project followed the following workflow:

```text
Raw Data
   ↓
Data Quality Assessment
   ↓
Data Cleaning
   ↓
Data Modelling
   ↓
DAX Measures
   ↓
Dashboard Development
   ↓
Interactive Analysis
   ↓
Business Insights
   ↓
Recommendations
```
